# 웹툰스튜디오스 (Webtoon Studios)

Next.js App Router 기반 웹툰 스트리밍 및 관리자 검수 프로젝트입니다.

## 주요 구현 기능
1. **회차별 권한 및 멤버십 잠금 시스템 (`src/app/page.tsx`)**
   - **1~5화**: 누구나 무료로 즉시 열람 가능
   - **6~100화**: 멤버십 전용 잠금 적용, 결제 모달에서 결제 완료 시 즉시 자동 잠금 해제 및 상태 유지(`localStorage`)
2. **관리자 전용 검수 모드 (`설정` 탭 상단)**
   - 기본 PIN **`2026`** 입력 시 잠금 해제되어 결제 없이 **1~100화 전체 회차 검수 가능**
   - 검수 모드 활성화 시 상단 헤더(및 뷰어 상단)에 **`관리자 검수중`** 배지 표시

## 실행 방법
```bash
npm install
npm run dev
```
